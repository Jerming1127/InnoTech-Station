校園 Fun Day 接食物遊戲・學生筆記（網頁版）
========================================

把整個資料夾上傳到學校網站即可，請保持這個結構：

  index.html        全班學生筆記（有步驟、截圖）
  b-tips.html       B 層提示卡（可選擇不放到公開目錄，或不把連結交給 C 層）
  styles.css
  images/

建議：
- 全班只分享 index.html 的網址。
- 如要給 B 層提示，另外分享 b-tips.html。
- 筆記由 Teachable Machine 的 Pose（姿勢）專案教起，類別名只用 Left 和 Right。

用瀏覽器打開 index.html 也可以先在本機預覽。
