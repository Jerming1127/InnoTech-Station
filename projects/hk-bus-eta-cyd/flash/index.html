巴士報站 · 一鍵燒錄

韌體版本 1.4.7 · CYD ESP32（4MB）
  1. 請用 Chrome 或 Edge 開啟本頁（不支援 Safari／Firefox）。
  2. 用 USB 線接上螢幕模組（CYD）。
  3. 按下方「一鍵燒錄」，在彈出視窗選取對應的序列埠（COM）。
  4. 等候進度完成即可。
注意：本頁必須以 HTTPS 或 localhost 開啟，Web Serial 才會生效。 首次燒錄建議選「清除並安裝」（Erase）。燒錄會覆寫裝置上的韌體與字型資料。
此瀏覽器不支援 Web Serial。請改用 Chrome 或 Edge，並以 HTTPS／localhost 開啟。
